# 256 Newsroom

Static prototype for 256 Newsroom, Uganda's Digital News Infrastructure.

## Open locally

Open `index.html` directly in a browser:

```text
/root/256-newsroom/index.html
```

Or serve it locally:

```bash
cd /root/256-newsroom
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```
